# Primal Code: downloads

Installers for **Primal Code**, a code editor built on the VS Code open-source core, with the AI agents you already pay for: the Agents window, and Claude Code, Codex and Gemini CLI side by side in the CLI panel.

- **Download:** the [latest release](https://github.com/MuhammadTalhaJaved-0303/primal-code-downloads/releases/latest) has the macOS, Windows and Linux installers and their checksums. The [website](https://primal-code-site.vercel.app) has the docs.
- **Report a problem:** [open an issue here](https://github.com/MuhammadTalhaJaved-0303/primal-code-downloads/issues/new), or use **Help › Report a Problem** in the app, which fills the issue in for you to read first. Issues are public: never paste an API key or a token.
- **Privacy:** [what Primal Code sends, and to whom](https://primal-code-site.vercel.app/privacy).
- **License:** [LICENSE.txt](LICENSE.txt), the license Primal Code ships under.

This repository also hosts the agent packages the app downloads the first time it needs them (the `agent-sdk-*` releases). They are public npm packages repackaged per platform, under their own licenses; no Primal source code lives here.
